01 / The research question

One forecast.
Two different scoreboards.

Aggregate velocity-field error is useful, but it does not describe every property of a flow. This work asks whether a model that is closer point-by-point is also closer in its resolved fluctuation-energy behaviour.

THE METRIC PARADOX
METRIC A / FIELD ACCURACY
↘

Closer to the measured velocity field.

Relative L₂ error compares predicted and measured velocity components over the evaluation window. Lower values indicate smaller field discrepancy under this metric.

Lower is better
METRIC B / FLUCTUATION ENERGY
↗

Further from the fluctuation-energy target.

The two-component temporal fluctuation-energy diagnostic captures behaviour that a single aggregate field score can conceal.

Lower error is better
02 / Experimental design

A frozen model.
A changed history.

The diagnostic pipeline changes the observed history while keeping the forecasting checkpoint fixed. It then measures how the forecast responds and whether the two evaluation metrics tell a consistent story.

THE PIPELINE
◌

Pair CFD and PIV

Matched numerical and experimental flow data around a NACA4418 airfoil. PIV provides the measured in-plane velocity history.

REAL + SIMULATED
⇢

Forecast the future

Map 20 observed PIV frames to 20 future frames on the 32 × 64 scoring grid.

20 INPUT / 20 OUTPUT
▦

Intervene on history

Replace selected cells' changing values with their temporal means. Compare energetic, low-energy and random masks.

FROZEN CHECKPOINT
⌁

Read two diagnostics

Measure velocity-field error, two-component fluctuation-energy error and domain-summed energy ratio.

COMPLEMENTARY METRICS
Hybrid Fourier–wavelet reference FNO CNO Transolver

The reference is a compact hybrid Fourier–wavelet operator with local convolution, temporal attention, source adaptation and residual forecasting. It is a comparison checkpoint, not a physics-ground-truth model.

03 / The central result

CNO moves in opposite directions.

Relative to the reference surrogate, CNO has a lower relative velocity-field error but a higher fluctuation-energy error. Switch between the two analysis subsets to inspect the reported estimates and confidence intervals.

05 / Output stress test

An error can improve
while energy gets worse.

On the selection subset, a mean-preserving attenuation of predicted fluctuations slightly improves both normalized benchmark errors, while the domain-summed fluctuation-energy ratio moves further below one.

SELECTION SUBSET
Relative velocity-field error0.120958 → 0.119692Lower benchmark error ↓
Relative fluctuation-energy error0.533389 → 0.528463Lower benchmark error ↓
Domain-summed energy ratio, RE0.815 → 0.756Greater under-energy ↑

This is a diagnostic stress test, not a held-out correction: attenuation gains were selected using both analysis subsets. It illustrates how sample-normalized errors and a domain-pooled energy ratio can rank predictions differently.

06 / Scientific boundaries

What the evidence
does not claim.

The conclusions are intentionally bounded by the benchmark, sampling design and intervention assumptions. These limitations are part of how the results should be read.

LIMITATIONS
One physical system

The evidence comes from a NACA4418 airfoil benchmark. It is not a broad cross-system validation.

Shared trajectory support

Both analysis subsets use the same 23 experimental trajectories. They are window-disjoint, not trajectory-disjoint, and do not establish out-of-trajectory generalization.

Equal area is not equal energy

Energetic and random masks cover the same fraction of valid cells but do not remove the same amount of fluctuation energy.

No physical counterfactual target

The modified input histories do not have known physically realizable future observations.

Possible intervention artifacts

Hard mask boundaries may introduce spectral artifacts. Smooth and energy-matched controls are needed.

Exploratory attenuation

Attenuation gains were selected on both subsets, so the stress test is not evidence of a held-out physical correction.
